<objective>
Add the protected `GET /trips/:tripId` read endpoint to `apps/api`: one DynamoDB `Query` on `PK = TRIP#<tripId>`, an email-keyed participation guard that returns a byte-identical 404 to non-members and to callers of non-existent trips (enumeration resistance), and an explicit-field `TripDetailResponse` shape with no internal keys. Extract the storage->DTO item mapper into a reusable module that locks the cross-phase attribute contract Phase 7's write path must honor.

Purpose: This is the security-critical read + authorization slice of the milestone (TRIP-02) and the code half of email-keyed identity (TRIP-03). The guard's byte-identical 404 is the whole point of the phase.
Output: `apps/api/src/routes/api.ts` gains the route; `apps/api/src/lib/tripDetail.ts` (new) exports `mapItemRecord`.
</objective>
